# Delivery roadmap

## Gate 0 — foundation (current)

Clean-room boundary, core contracts, identity lifecycle, permissions, schema, CLI diagnostics, dependency inventory, CI, and reproducible MySQL environment.

## Gate 1 — playable vertical slice

Character creation/selection, spawn, wallet ledger, starter inventory, one legal profession, garage, administration audit, and a minimal NUI. Exit: a new operator can install from documentation and two players can complete the loop without manual database edits.

## Gate 2 — paid pilot

Qbox compatibility adapter plus Economy + Professions module, entitlement delivery, updater with rollback, telemetry opt-in, backups, and ticket workflow. Exit: three independent pilot operators complete installation and upgrade exercises.

## Gate 3 — production launch

Load/soak evidence for the supported player tier, incident runbooks, migration guarantees, pricing and support capacity. Claims such as “128 players supported” are published only with reproducible test evidence and live pilot history.

NoPixel is inspiration for product discipline, not a feature checklist. Differentiation is operator experience, reliable upgrades, coherent gameplay contracts, and support quality.
